========================================================================
Sanskriti 3D - Images Directory Instructions
========================================================================

Place representative photographs or render previews for the sites into 
this folder matching these exact filenames:

  - ajanta.jpg
  - ellora.jpg
  - konark.jpg
  - redfort.jpg
  - tajmahal.jpg

RECOMMENDED FREE & LEGAL SOURCES FOR IMAGES:
  1. Unsplash (https://unsplash.com)
  2. Wikimedia Commons (https://commons.wikimedia.org)
  3. Pexels (https://pexels.com)

NOTE ON FALLBACK MECHANISM:
If images are missing, the UI automatically catches the load error (onerror handler)
and generates a dynamic SVG/placeholder banner with the monument's name.
