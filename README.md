## 🚀 How to Run locally in VS Code

Web browsers block loading local external assets (like `.glb` files and ES6 imports) using the `file://` protocol due to CORS security policies. Use one of these methods to launch local execution:

### Option A: Using VS Code Live Server (Recommended)
1. Open **VS Code**.
2. Click **File > Open Folder...** and select the `Sanskriti3D` directory.
3. Install the **Live Server** Extension by Extension Marketplace (`ms-vscode.live-server`).
4. Open `index.html`.
5. Click **"Go Live"** in the bottom status bar or right-click `index.html` and select **"Open with Live Server"**.
